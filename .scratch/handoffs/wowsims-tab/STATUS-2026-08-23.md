## Two new gates in `pnpm verify`

- `pnpm fork-universes:check` — byte-compares all eight files the fork's
  `upgrades/data/PROVENANCE.md` table maps against their `data/` sources. Skips
  with a message when the gitignored clone is absent, so CI is unaffected.
  Refresh with `python scripts/sync_fork_universes.py --write`.
- `pnpm pool-listings:check` — regenerates `data/pool-listings/{ret,feral}-p3.md`
  and byte-compares. Fails loudly naming `pnpm sync:wowsims:restore` when
  `vendor/wowsims/db.json` is missing, rather than skipping.

Both are byte-compares, not judgements: a regeneration that drops an item passes
the moment someone commits the regenerated file. The protection is that the diff
is legible and names items.

## Traps this run hit, so the next one does not

New this run:

- **Serve `dist`, not `dist/tbc`.** The built bundle hardcodes a `/tbc/` prefix.
  Serving `dist/tbc` as the web root 404s the entry script and the page renders
  **blank white with no console error** — indistinguishable from a broken build.
  Correct: `cd vendor/tbc-new-fork/dist && python -m http.server 8975`, then
  `http://localhost:8975/tbc/druid/feralcat/`. (Feral's route is `feralcat`,
  not `feral`.)
- **The browser extension can open your tab in a 0x0 window.** Such a tab reports
  `visibilityState: hidden` **permanently**, no matter which window the owner
  fronts, so it looks exactly like "the owner has not fronted the page" and no
  amount of polling fixes it. Diagnose with `window.outerWidth/outerHeight`; fix
  with the extension's `resize_window` (1600x1000 worked), after which the tab
  reports `visible` and `hasFocus: true`.
- **An empty filter view renders a one-cell "No upgrades found above the
  cutoff." row.** A naive `tbody tr` count treats it as data — it inflated one
  filter's row count and produced a phantom item that appeared to match three
  filters at once. Count only rows with `cells.length >= 5`.
- **Python writes to fork files need `newline='\n'`.** `pathlib.write_text()`
  without it translates `\n` to `\r\n` on Windows. `core.autocrlf=false` and
  there is no `.gitattributes`, so git stores exactly what you wrote: two
  commits flipped `translation.json` and `upgrades_tab.tsx` wholesale to CRLF
  (~2,530 and ~2,289 phantom line changes) and had to be rewritten. **Check the
  per-file `--stat` is content-sized before every fork commit.** Note
  `upgrades/engine/PROVENANCE.md` is genuinely CRLF at rest — normalise the
  upstream files, leave that one alone.
- **`npm --prefix <fork> run <script>` fails on Windows.** npm spawns cmd.exe,
  which cannot run the scripts' POSIX-relative `node_modules/typescript/bin/tsc`.
  Use `cd <fork> && npm run <script> --script-shell=bash` after `fnm env`.

Carried forward from tranche 1, all still true:

- **Rebuild `lib.wasm` whenever you rebuild `sim_worker.js`**, even with no Go
  change. A wasm built by an older Go toolchain never instantiates under newer
  glue, and it fails **silently** — no gear, no presets, empty Settings, no
  console error.
- **Verify a bundle with a gear-set item id, not a source identifier.** oxc
  minification renames identifiers.
- **`cd` into the fork is fine after `fnm env` + `fnm use 22.17.1`**, and the
  vite build *requires* it (`vite.config.mts:128` resolves `assets/locales`
  against the process cwd).
- **Do not run `npm run format` in the fork.** It is a writer over ~693 files.
- **A background tab is not a measurement surface.**

## What the pool listings do and do not settle

They are the detector tickets 17 and 173 asked for, at phase 3 for ret and
feral. They do **not** decide anything: an item the rules cannot explain is
reported under "Unexplained", never added to a pool. Three limits worth knowing
before treating a zero as reassurance:

- Coverage is phase 3, ret and feral. Other phases and specs are unwatched.
- Three of the plan's reason categories (weapon/hand, `eligible_d7`, class
  allowlist) **cannot fire** on the wowsims-only side, because the audited
  membership is defined by that same eligibility rule. They print as a
  structural zero, not as three passing checks.
- The audit says every difference has a citable rule. It does not say every
  rule is right.
