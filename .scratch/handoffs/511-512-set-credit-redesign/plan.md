## Approach

**Findings (files under `.scratch/stage-gate/upgrades-tab-closeout/round-2e/`).** `d1-noise.md`: a net 4pc figure is a difference of 5–6 sims; the 4.81 floor is below one combined se. `measure-path.md`: the tab recorder `scripts/tab-fixtures/record.mjs` runs the fork engine at the pin and already captures per-bonus `bonusDps`, `se`, `bonusDpsNet`, `selfConfound` in `ranking.setBonuses[]`; `data/tab-fixtures/ret-p3-p2.json` is scenario I (same controls, same figures: CF4 21.07 ± 10.08 with selfConfound 4.80, J4 15.32 ± 5.38, Lightbringer 2pc −3.14 ± 4.44, 4pc −4.22 ± 5.43); there is no fork CLI binary and the core CLI harness runs upstream `17a8fb28`, not the fork; the proto has no set-bonus switch, so the package-difference method is the only request-level measurement; the current 4pc `se` counts the baseline and prefix singles (which cancel) and omits `se_P2`; every package/vacate/pair sim uses `seeds[0]`, so the independent-sum se is an upper bound; iterations are settable per run, seeds are not. `d3-sets.md`: ~60 `NewItemSet` registrations; sets bind to items by `Name` (and Go `ID` when present); `data/items/index.json` gives the name→setId join (Wastewalker 659, Burning Rage 566, Primal Intent 619); `scripts/generate_sim_implemented_effects.py` already scans the fork tree under a lock guard with a `verify` check. Recordings inventory (reported to the orchestrator): `packages/core/test/fixtures/synthetic-roster-recordings.json` is a live recording (`npx tsx scripts/record_synthetic_fixtures.mjs`, upstream wowsimcli), 3 rows, 315/252/417 keys, replayed by `synthetic-fixtures.test.ts`; widening adds unrecorded keys, so it must be re-recorded; the tab fixtures are 5 files, checked by `check_tab_fixtures.py` via `git diff` between the fixture's `forkSha` and HEAD on engine input paths (warn-only for input drift, fatal on schema/forkSha); E-W3 parity builds its own recordings on the slamaltman gear and is affected only if that gear wears a newly admitted set at ≥2 pieces. Non-tier sets with ≥2 candidates in the ret/feral universes: 566 Burning Rage (ret p2–p5), 583 Gladiator's Vindication (ret p3–p5), 573 Fel Skin (feral p2–p5), 584 Gladiator's Sanctuary (feral p3–p5, 4 pieces). 659 Wastewalker and 619 Primal Intent appear only as worn pre-raid gear, so they matter for breaks, not for credit.

**The rule (F2).** A registered `(setId, threshold)` bonus counts — for credit and for break charges alike — when the committed calibration file `data/set-bonus-calibration.json` holds a measurement for it on the fork sim at the pin with `|B| > 2 · se_B`, where `se_B` is the difference-form se (C9) at the calibration iterations (10000). Registered but unmeasured, or measured and not clearing 2·se: not implemented, which is today's behaviour. The list of hand overrides is for cases the rule cannot decide, and starts empty; the only admissible entry is a bonus whose two calibration runs disagree on the 2·se test, which is recorded as `undecided` (not counted) with a ticket. What this does: for ret, Crystalforge 4pc (a heal) and Justicar 4pc (a judgement the default APL never casts) fall out if the residue probe says the method is sound, because a bonus that cannot move DPS cannot clear 2·se at 10000 iterations except by residue; Crystalforge 2pc (mana) stays in only if it measures real; Burning Rage 2pc and Lightbringer are decided by their numbers. For feral, Malorne, Thunderheart, Nordrassil 4pc (all > 8 se at 3000) stay in; Wastewalker 2pc/4pc, Fel Skin 3pc, Gladiator's Sanctuary and Primal Intent are decided by their numbers. For other specs: nothing new is credited or charged until that spec is calibrated (epic 452); the calibration file is keyed by `setId:threshold` and records the spec it was measured on, which is exact this round because ret (plate) and feral (leather) share no set, and a shared set between two later-supported specs (Wastewalker for feral and rogue) is a known limit recorded on 512 for 452. Run time: the rule adds package sims only for admitted sets, so the count of extra package sims per spec is the count of admitted non-tier sets with ≥2 candidates (at most 2 for ret, 2 for feral from the universe counts above), and break sims only for worn admitted sets.

**Why this beats the alternatives.** A k×se gate on each run's own figure (candidate a) fails its win condition on the existing data: CF4 is 2.09 se at 3000 iterations with the current se, so it would pass. More iterations per run (b) fixes only the noise half and costs ~3× wall time on every run. A per-spec hand list (c) is the growing table the owner rejected. Calibration once, at high iterations, with the correct se, is the only option that is both measurable and constant per pin. Extending the hand table (design B for D3) is rejected for the same reason as before: nothing gates drift on the next pin move.

**Residue probe (F3, F4).** Justicar 4pc is the cleanest known-inert package on ret: four pieces from zero worn, no 2pc term (626 2pc is not implemented), and verification.md V0 recorded zero Judgement of Command casts. Re-running scenario I's exact controls at 10000 iterations tells the three cases apart, each with its consequence written before the run (Step A3).
