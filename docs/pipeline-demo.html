Honest Caveats

Recall (Input)

100/123 (81.3%) — measured against the Wowhead P3 BiS guide when that guide is used as a pipeline input source.

Recall (Held-Out)

78/123 (63.4%) — the same Wowhead guide held out and used purely as an answer key. This is the honest accuracy ceiling given scope and data.

Junk Filter

A junk filter has been measured but is deliberately NOT applied at runtime. It would reject 119 of 362 items as caster-only (32.9%). It stays off until that rejection rate is validated against simulated results, to avoid hiding errors in the filter itself.

Scope

Non-raid sources (badge vendors, reputation, crafting, heroic dungeons) are deliberately out of scope. This is why the ranged/libram slot shows only 3 items—most ret librams drop outside raids or are quest rewards.
