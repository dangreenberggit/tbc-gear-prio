# Phase 4 and phase 5 live pass over the 11 DPS specs (2026-11-03)

## Verdict

All 22 runs (11 DPS specs, phases 4 and 5) finished and count: each JSON has
`done: true`, no panic, no timeout, and the harness exited 0. The SME seats
rated 6 runs `trust` and 16 `trust-with-caveats`; none `do-not-trust`. In
every run where wowsims ships its own next-phase preset, the items that
preset adds show as gains, with one known exception: at phase 5, single
swaps that break a worn 4-piece set show as losses (ticket 523). The pass
filed four new tickets (750-753), added evidence to four open tickets (309,
523, 620, 641), and found nothing new for 746. For epic 452 this pass is
evidence about the tab's output per spec and phase; it is not one of the
epic's bar items, and one question goes to the owner (Q-452-golden).

## Catch-up checks

The wowsims catch-up to v0.0.153 changed item data the tab reads. Results
from the four SME handoffs:

- **(i) Weapons changed from main hand to one hand.** Enhancement offers
  Dragonstrike, Dragonmaw and Fool's Bane in the off hand (phase 4: -16.4,
  -27.2, -87.2; phase 5: -21.6, -32.3, -83.1). Fury warrior offers Fool's
  Bane in the off hand; its best slot for the two Dragon maces is the main
  hand. Rogue's best slot for all three is the main hand. Hunter offers none,
  which is right: hunters cannot use maces. The order is plausible in every
  run. The Decapitator appears in no run: wowsims lists it as missing its
  effect (`missing_effects_auto_gen.ts:1599`, read by the SME).
- **(ii) Hallow's End items under new ids.** Ring of Ghoulish Delight
  (281907), The Horseman's Signet Ring (281911) and Witches Band (281915)
  appear in all 22 runs. The Horseman's Helm (281919, plate) appears only
  for ret and warrior. The Horseman's Blade (281923) appears in no run.
- **(iii) Stonebreaker's Totem.** Elemental shows it at both phases, below
  the cutoff (-72.5, -73.9), costing about the worn totem's value since its
  effect is an attack-power proc. Enhancement shows it at phase 4 at +7.8,
  above the cutoff; at phase 5 the start preset already wears it, so it has
  no row.
- **(iv) Ferocious Bite keeps excess energy on a miss.** Cannot be read from
  this pass: the change (fork commit `4564b6e8a`) is an ancestor of both
  `119b9f676` and `13a980cf3`, so no before/after pair exists, and the
  phase-4 feral run matches the 10-25 run row for row.
